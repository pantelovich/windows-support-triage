# Windows Support Triage

PowerShell 7.4 or newer. Pester for tests and PSScriptAnalyzer for linting.
Keep collection local and read only. Write reports only to the output directory.
Never restart services, clear queues, change registry values or reboot.
Missing evidence is unknown, never a pass. Collect only explicitly selected fields.
Do not collect usernames, hostnames, serial numbers, event messages or credentials.
Only fictional fixtures belong in Git. Keep live reports ignored.
Use plain British English. Findings are evidence, not confirmed root causes.
Run lint, unit tests and the demo after changes. Distinguish Windows smoke results.

## Work routing

Use Ruflo routing when deciding whether work needs delegation.
Keep small changes in one session. No swarm is required for the initial version.
Implementation covers collection and reports. Review checks privacy and failure
handling. Verification covers fixture rules, output files and Windows smoke tests.
Do not describe a routing recommendation as a completed agent review.

On case insensitive filesystems AGENTS.md and agents.md are the same file.
This document therefore holds both the project rules and routing notes.
