# Sources and role relevance

Reviewed 4 November 2026.

The supplied support adverts emphasise Windows, hardware, printers, user
communication, troubleshooting and incident records. A separate
[NHS Service Desk Analyst advert](https://www.jobs.nhs.uk/candidate/jobadvert/C9334-26-0344)
also lists Windows 10/11, triage, precise records, escalation and printer support.
That advert is closed and is used as a skills benchmark, not an open vacancy.
No single project covers every employer requirement.

Microsoft references:

- [Get-CimInstance](https://learn.microsoft.com/en-us/powershell/module/cimcmdlets/get-ciminstance)
- [Win32_OperatingSystem](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-operatingsystem)
- [Get-WinEvent](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.diagnostics/get-winevent)

Registry restart indicators are limited heuristics. They are not a Windows
Update compliance API and may not represent every reason for a restart.
